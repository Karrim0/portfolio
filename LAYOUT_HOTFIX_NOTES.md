# Portfolio layout hotfix

This patch fixes four visual issues:

- Keeps the desktop hero inside the first viewport on standard desktop screens.
- Prevents the Gym Crew native-extension note from overlapping the console footer.
- Reworks the client testimonial into a compact recruiter-friendly layout.
- Removes the unintended circular badge around the footer wordmark dot.

The patch intentionally does not change project content, ordering, metadata, or responsive mobile hero behavior.
