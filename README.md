# Kareem Hanafy — Web Portfolio

A web-first professional portfolio built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Positioning

- Primary focus: frontend and full-stack web development
- Featured case studies: Kidorly, Menoufia University Portal, and Fourmap
- Supporting work: MFM Egypt, Shailla Farms, EquipLink Egypt, Gym Crew, and Prime Cart
- Mobile experience is intentionally presented as a small native extension of the Gym Crew web product

## Highlights

- Recruiter-focused hero and web engineering positioning
- Three detailed web case studies with role, challenge, outcome, and interactive image galleries
- Web-first capability section covering modern frontend, backend/data, and production delivery
- Verified client feedback from the Fourmap project
- Wordmark navigation and custom geometric favicon
- SEO metadata, dynamic Open Graph image, sitemap, robots, and JSON-LD
- Responsive layouts, reduced-motion support, and accessible project controls

## EmailJS

The contact form supports the following public environment variables:

```env
NEXT_PUBLIC_EMAILJS_SERVICE_ID=
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=
```
