# Mobile, Identity & Cursor Polish

## What changed

- Added a personal hero identity strip with Kareem's portrait, full name, role, and availability.
- Kept the positioning web-first while making the hero feel authored by a real engineer rather than a generic template.
- Simplified the mobile hero system visual into a compact product-engineering card.
- Reduced mobile typography density, spacing, section padding, and card radius for better visual comfort.
- Rebuilt featured-project galleries on mobile with a large 8:5 preview and horizontally scrollable thumbnails.
- Improved mobile project buttons, touch targets, cards, capability sections, About, Contact, testimonial, and footer spacing.
- Added a professional precision cursor for fine-pointer desktop devices only.
- The cursor uses delegated interaction states, cleans up all listeners, respects reduced motion, and never runs on touch devices.
